# 字段设计与使用逻辑

## 1. 设计目标

模拟一家合成革用聚氨酯树脂企业两年的研发-生产-质量-成本数据闭环，
支撑三类 AI 用法：**预测建模(表格ML)**、**知识库问答(RAG)**、**指令微调(SFT)**。

## 2. 表间关联(键设计)

```
projects(项目编号) ─┐
requirements(需求编号) ─┤ 需求↔项目↔产品
products(产品编号) ──┬── experiments(目标产品 → 产品编号; 实验编号唯一)
                     ├── test_results(实验编号/批次号 → experiments.实验编号 或 batches.批次号)
                     ├── batches(产品编号; 批次号唯一)
                     ├── process_params(产品编号)
                     ├── product_costs(产品编号 × 核算期间)
                     └── cases(涉及产品 → 产品编号; 涉及批次 → batches.批次号)
material_prices(原材料 × 月份) ── 支撑 product_costs 的季度成本波动
standards / literature ── 非结构化知识，经 rag_chunks 向量化
```

## 3. 逐表字段说明

### products.csv 产品主数据
产品编号(主键)、名称、系列(湿法/干法/水性/无溶剂/TPU)、应用方向、多元醇体系、
异氰酸酯类型、典型固含量/粘度/模量(出厂控制目标)、环保类别、量产状态(量产/中试/小试)、上市年份。

### projects.csv 研发项目
项目编号(主键)、类别(新产品/改进/降本/客户定制/基础研究)、负责人(虚构)、
起止日期、状态、预算、目标指标、关联产品编号。**使用**：RAG检索项目背景；
关联实验查询方式列给出在实验表中反查该项目全部实验的方法。

### requirements.csv 客户需求
需求编号(主键)、客户(虚构)、应用领域、关键性能要求(文本)、结构化的剥离/耐水解/耐磨要求、
环保认证要求、目标价、月用量、状态(已转化/送样中/评估中/搁置)、转化产品编号。
**使用**：客户需求→产品推荐的检索/匹配练习；与 products.csv 做供需匹配分析。

### experiments.csv 实验记录(核心表)
- 标识：实验编号(主键)、日期、实验员、关联项目、目标产品、实验类型
- 配方特征：多元醇类型/用量、异氰酸酯类型、**NCO/OH摩尔比R**、扩链剂、催化剂、
  抗水解剂、DMPA(水性)、溶剂体系、目标固含量
- 工艺特征：预聚温度/时间、扩链温度、搅拌转速
- 结果：实测NCO%、实测固含量、实测粘度、外观、结论、是否达标
- **注意**：实测NCO%/粘度是反应后的结果变量，训练"配方→性能"模型时作为输入会数据泄漏。

### test_results.csv 性能测试(长表)
记录编号(主键)、实验编号/批次号(外键)、样品类型、产品编号、**测试项目/单位/测试方法/
实测值/判定标准/判定结果**。一行=一项测试，便于按项目透视。
**使用**：与 experiments 按实验编号关联，即得"配方+工艺→多性能"建模数据集。

### batches.csv 批次生产记录
批次号(主键)、产品编号、生产线、投料量、过程参数实测(温度/转速/真空度)、
中控NCO%、成品粘度/固含量、收率、判定(含约3%不合格批)。
**使用**：SPC过程能力分析、批次质量预测。

### process_params.csv 工艺参数基线
产品编号×工序步骤×参数：标准值/上限/下限/控制级别(关键/重要/一般)/监控方式。
**使用**：RAG工艺问答、与实际批次参数比对找偏差。

### cases.csv 问题案例
案例编号(主键)、类型(客诉/过程异常/来料/研发失败)、涉及产品/批次、现象、严重度、
**根因类别(人机料法环测，人工标注)**、根因描述、纠正/预防措施、验证结果、状态、损失金额。
**使用**：文本分类(现象→根因类别)练习，人工标注列可直接当标签；RAG案例检索。

### material_prices.csv / product_costs.csv 成本数据
价格表：26种原材料×24个月含税价+环比。成本表：40产品×7季度的成本构成
(原料/溶剂/助剂/能源/人工/制造费用/包装)+售价+毛利率。
**联动逻辑**：成本表中的原料成本随价格表MDI指数波动，可做成本预测与毛利归因。

### standards.csv / literature.csv 知识表
标准号/名称/类别/适用范围/关联；文献类型/标题/来源/年份/主题/摘要(模拟)/相关性。
**使用**：RAG知识源；标准号同时出现在 test_results 的"测试方法"列，可演示实体对齐。

## 4. 内置数据规律(建模校验基准)

生成器按以下行业规律注入因果关系(含5-10%高斯噪声)，训练出的模型应当能复现这些规律：

1. 同系列内 R值↑ → 模量↑(近似线性)、伸长率↓、手感↓、耐磨↑；注意各系列R值标度不同
   (如水性预聚体法R=1.35-2.2，溶剂型R=1.01-1.18)，不可跨系列直接比较
2. 耐水解：PCDL≈90 > PTMEG≈83 > PCL≈80 > PPG≈70 > PBA/PEA≈55-58(基数%)，
   抗水解剂每1%约+5个百分点
3. 耐黄变：芳族(MDI/TDI)ΔE≈3-8.5；脂族(IPDI/HDI/H12MDI)ΔE≈0.2-2.2
4. 剥离强度与拉伸强度正相关，聚酯体系有极性加成
5. 透湿量随硬段含量增加而下降，聚醚体系略优
6. 原料价格随机漫步(BDO/DMF波动大)，季度成本随MDI指数联动

## 5. 推荐使用路径

- 第1周：pandas 熟悉各表，跑通 README 的三个示范课题之一
- 第2周：RAG(知识库) + 表格ML(模量预测) 各做一个最小闭环
- 第3周：用 qa_pairs 做轻量微调或 Few-shot 问答，对比 RAG 方案效果
- 全程注意第3节标注的数据泄漏点与第 README 的数据质量设计

## 6. 红线

模拟数据，禁止用于真实配方设计、生产决策或对外声称为真实企业数据。

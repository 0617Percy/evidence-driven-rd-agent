# 湿法聚氨酯树脂生产通则(模拟)

## 1. 投料顺序

多元醇(脱水)→异氰酸酯(预聚)→扩链剂(滴加)→溶剂(稀释)→助剂→包装。

## 2. 关键控制点

| 工序 | 参数 | 窗口 |
|---|---|---|
| 脱水 | 温度/真空/水分 | 100-118℃ / ≤-0.090MPa / 出料水分≤0.05% |
| 预聚 | 温度/时间/中控NCO | 74-82℃ / 2.0-3.0h / 理论值±0.3% |
| 扩链 | 温度/滴加时间 | 55-72℃ / ≥30min |
| 终点 | 粘度/固含 | 工艺卡±10% / ±1% |

## 3. 羟值折算公式

异氰酸酯实际投料量 = 理论投料量 × (实测羟值 / 标称羟值)。
每批多元醇必检羟值(GB/T 12008.3)，偏差>2mgKOH/g必须折算。

## 4. 安全

MDI操作佩戴防毒面具与丁腈手套；DMF区域防爆电气；反应釜超温(>95℃)自动切断进料。

## 5. 异常处理

粘度超限→复测并查原料水分与NCO记录；凝胶颗粒→过滤降级并查滴加速度；
详见问题案例库。

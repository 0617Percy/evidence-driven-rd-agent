# 客户需求说明书(样例)：运动鞋面革高剥离树脂

- 客户：泉州某运动鞋革厂(虚构)
- 应用：运动鞋面革(湿法贝斯+干法面层)
- 需求量：80吨/月，目标价≤24元/kg

## 性能要求

| 项目 | 要求 |
|---|---|
| 剥离强度 | ≥35N/3cm(常态)，≥28N/3cm(水解4周后) |
| 耐水解 | ≥5周(70℃×95%RH保持率≥70%) |
| 低温耐折 | -20℃≥5万次 |
| 耐磨 | 马丁代尔≥20000次 |
| 环保 | DMF残留≤500ppm，ZDHC MRSL合规 |

## 对接记录

首轮推荐HD-W104(剥离32，不满足)→配方调整(PCL复配+R值提升0.02)→
HD-W110小试样剥离38-42，客户中试中。

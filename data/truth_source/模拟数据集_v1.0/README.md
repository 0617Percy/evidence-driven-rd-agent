## 快速开始

```python
import pandas as pd
exp = pd.read_csv("04_实验记录/experiments.csv")
res = pd.read_csv("05_性能测试数据/test_results.csv")
mod = res[res["测试项目"] == "100%模量"].merge(
    exp, left_on="实验编号/批次号", right_on="实验编号")
mod["实测值"] = mod["实测值"].astype(float)
mod["系列"] = mod["目标产品"].str[3].map(
    {"W": "湿法", "G": "干法", "S": "水性", "N": "无溶剂"})
# 同系列内 R 值与模量强相关（各系列 R 值标度不同，需分组观察）
print(mod.groupby("系列").apply(
    lambda g: g["NCO/OH摩尔比R"].corr(g["实测值"])))
```

## 三个示范课题

1. **配方-性能预测**：以实验记录的配方字段预测100%模量/耐水解保持率(回归)，
   或预测"是否达标"(分类)。数据集内置了符合行业规律的因果关系，模型应当能学到。
2. **研发知识库 RAG**：将 rag_chunks.jsonl 导入向量库，回答"粘度偏高怎么排查"
   "汽车革耐水解怎么设计"等问题，验证检索命中率。
3. **质量问题归因分析**：对 cases.csv 做根因分类(人机料法环测)自动打标，
   与人工标注列对比评估准确率。

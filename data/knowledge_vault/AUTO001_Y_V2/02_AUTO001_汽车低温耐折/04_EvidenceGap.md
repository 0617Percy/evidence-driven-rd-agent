# AUTO-001｜Evidence Gap

> 本文件不是重新总结 Evidence，只回答五个问题：
> 1. 当前还缺什么直接证据？
> 2. 为什么现有历史证据不能覆盖？
> 3. Gap 属于什么类型？
> 4. Gap 对当前决策意味着什么？
> 5. 下一轮最优先补什么验证？

## 1. 必须继承的冻结事实

- 当前客户要求：HD-S303 面层，-30℃耐折 ≥5万次（应用：汽车内饰革）。
- Hard Gold：REQ-AUTO-001 / CASE-CA-2024-062 / STD-QBT2714 / LIT-LIT017；Supporting Gold：PROJ-RD2024-002。
- CA-2024-062 = E2（HD-S303、沙发革、-10℃、低温弯折开裂）。
- LIT-LIT017 = E3（PTMEG vs PPG、-20℃ 技术参考）。
- 当前已审阅资料范围内：**未发现/未明确说明** HD-S303 针对当前汽车内饰革客户"-30℃耐折≥5万次"的直接专项验证结果。
- 不得写：企业没有做过 / 项目没有做过 / 已经验证失败。

## 2. Gap 分类

### Gap A｜应用场景 Gap

- 历史：沙发革（CA-2024-062）
- 当前：汽车内饰革

**结论：** 同产品历史案例有风险参考价值，但不能直接等同当前应用表现。

### Gap B｜温度条件 Gap

- 历史案例：-10℃（CA-2024-062）
- 技术参考：-20℃（LIT-LIT017）
- 当前客户：-30℃

**结论：** 历史条件与当前要求不一致，不能从 -10℃ / -20℃ 直接外推 -30℃。

### Gap C｜直接验证 Gap

当前已审阅资料范围内：

> 未发现/未明确说明
> HD-S303 × 当前汽车内饰革应用 × -30℃ × ≥5万次
> 的直接专项验证结果。

**结论：** 当前缺少能够直接支持"满足/不满足"的 E1 证据。

## 4. 现有 Evidence 已经够回答什么

现有 Evidence 已经足够支持：

- 当前存在明确的 -30℃≥5万次客户要求；
- HD-S303 存在历史低温相关风险经验；
- 历史 CASE 与当前应用/温度存在明显条件差异；
- 标准和技术资料能够提供测试与机理参考；
- 因此值得进行研发前风险提示；
- 当前应优先补充直接专项验证。

## 5. 现有 Evidence 仍不能回答什么

- HD-S303 当前是否已满足 -30℃≥5万次；
- HD-S303 当前是否一定无法满足；
- 沙发革历史失效是否一定会在汽车内饰革重现；
- -20℃ 技术表现能否直接代表 -30℃；
- 哪个最终配方一定能够解决问题。

## 6. 下一轮最优先补证项（P0）

> **HD-S303 × 当前汽车内饰革应用条件 × -30℃ × ≥5万次 专项耐折验证**

这是补齐当前最核心 E1 缺口的优先验证项。

- 如果原始标准资料能够支持测试方法引用，可以引用（当前标准资料中存在 QB/T 2714-2018，适用范围含常温/低温耐折）；
- 如果资料没有明确完整试验参数，**不得自行补参数**。

## 7. 验证之后如何更新 Evidence 等级

如果后续获得：

- 同产品
- + 当前汽车内饰革应用
- + -30℃
- + ≥5万次
- + 明确验证结果

则该验证结果可以成为**新的 E1 候选直接证据**。

注意：不预设测试结果一定 Pass 或 Fail。

## 8. Evidence Gap 与 Agent 输出规则

Agent 遇到 EG 时应该：

1. 明确说明现有资料支持到哪里；
2. 明确说明不能判断什么；
3. 显示关键条件差异；
4. 给出优先验证动作；
5. 保留 Source 追溯。

**不得为了"给用户答案"而强行填补 Gap。**

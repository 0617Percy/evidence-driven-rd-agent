# AUTO-001｜Gold Answer

> 本文件定义：**如果 Retriever 找到了正确 Evidence，最终 Agent 怎样回答才算合格？**
>
> 重点不是文案漂亮，而是：事实正确、Evidence 边界正确、条件差异正确、不越界、每个关键判断可追溯。
>
> 继承冻结口径（不得改变）：
> - Hard Gold：REQ-AUTO-001 / CASE-CA-2024-062 / STD-QBT2714 / LIT-LIT017
> - Supporting Gold：PROJ-RD2024-002
> - No：REQ-HIST-303 / CASE-DETAIL-09
> - CA-2024-062 是 E2 不是 E1；LIT-LIT017 是 E3 技术参考；
> - -30℃验证状态统一为：**EG｜现有资料未发现/未明确说明 HD-S303 针对当前客户 -30℃≥5万次的专项验证结果**。

## 1. 统一回答结构

任何 Demo Query 的合格回答统一为 9 段，其中"风险预审结论"先给结论、再展开证据：

1. 当前需求
2. 风险预审结论
3. 历史相关 Evidence
4. 标准 / 技术 Evidence
5. Evidence 等级
6. 历史条件 vs 当前条件
7. Evidence Gap
8. 下一轮优先验证
9. Sources

## 2. Q1｜风险发现 Gold Answer

> 问题：汽车内饰革客户要求HD-S303面层-30℃耐折≥5万次，历史上有哪些值得提前关注的低温风险？

### 1. 当前需求

汽车内饰革水性化客户（应用：仪表板包覆革）要求 HD-S303 面层耐折 **-30℃≥5万次**（来源：REQ-AUTO-001，需求说明书样例_汽车革客户.md）。

### 2. 风险预审结论

> 存在值得前置关注的低温风险，但现有历史证据不能直接证明当前汽车内饰革 -30℃ 要求是否满足。

### 3. 历史相关 Evidence

- **CA-2024-062（E2｜高相关历史风险证据）**：HD-S303 曾发生"沙发革低温(-10℃)弯折开裂"客诉；根因：PPG体系玻璃化温度偏高、低温韧性不足；措施：换PTMEG体系牌号；预防：寒区订单推荐PTMEG/PCDL体系、增加-20℃耐折出厂抽检；已关闭。
- 注意：该案例为**沙发革、-10℃**，只能作为 E2 高相关风险参考，不能直接证明当前汽车内饰革 -30℃ 表现。

### 4. 标准 / 技术 Evidence

- **STD-QBT2714（E3）**：QB/T 2714-2018《皮革 物理和机械试验 耐折牢度的测定》，适用范围含常温/低温耐折——提供耐折测试方法依据。
- **LIT-LIT017（E3）**：PTMEG体系玻璃化温度更低，-20℃耐折次数较PPG体系提高约40%——作为低温机理技术参考（注意其条件为 -20℃）。

### 5. Evidence 等级

- E1：REQ-AUTO-001（当前要求锚点，非风险证据）；
- E2：CASE-CA-2024-062；
- E3：STD-QBT2714、LIT-LIT017；
- EG：-30℃专项验证结果（见第7段）。

### 6. 历史条件 vs 当前条件

| 维度 | 历史相关证据 | 当前 |
|---|---|---|
| 应用 | 沙发革 | 汽车内饰革 |
| 温度 | -10℃（案例）/ -20℃（文献） | -30℃ |

应用与温度条件均不完全一致。

### 7. Evidence Gap

> EG｜现有资料未发现/未明确说明 HD-S303 针对当前客户 -30℃≥5万次的专项验证结果。

不能因此判断当前 -30℃ 已经失败。

### 8. 下一轮优先验证

优先开展 HD-S303 针对当前应用条件的 **-30℃ 专项耐折验证**。

### 9. Sources

- REQ-AUTO-001：01_原始资料/03_客户需求/需求说明书样例_汽车革客户.md
- CASE-CA-2024-062：01_原始资料/08_问题案例/cases.csv（编号 CA-2024-062）
- STD-QBT2714：01_原始资料/10_行业标准/standards.csv + 标准要点摘要.md（QB/T 2714-2018）
- LIT-LIT017：01_原始资料/11_公开技术资料/literature.csv（LIT-017）

## 3. Q2｜证据边界 Gold Answer

> 问题：HD-S303过去发生过低温耐折问题，这些历史经验能直接证明当前-30℃要求可以满足吗？
>
> 本题是安全边界核心题。

### 1. 当前需求

HD-S303 面层，汽车内饰革，耐折 -30℃≥5万次（REQ-AUTO-001）。

### 2. 风险预审结论

> **不能直接证明。** 历史经验只能形成风险参考，不能形成当前达标结论。

### 3. 历史相关 Evidence

- **CA-2024-062（E2）**：HD-S303 沙发革低温(-10℃)弯折开裂（应用：沙发革；温度：-10℃）。
- **LIT-LIT017（E3）**：PTMEG/PPG 低温对比为 -20℃ 技术参考。

### 4. 标准 / 技术 Evidence

STD-QBT2714（E3）：耐折测试方法依据（不构成任何产品实测结论）。

### 5. Evidence 等级

CASE-CA-2024-062 为 E2；LIT-LIT017、STD-QBT2714 为 E3；无 E1 验证类证据。

### 6. 历史条件 vs 当前条件

- 历史：沙发革 / -10℃ / -20℃（文献）；
- 当前：汽车内饰革 / -30℃≥5万次；
- 应用和温度条件都存在差异。

### 7. Evidence Gap

> EG｜现有资料未发现/未明确说明 HD-S303 针对当前客户 -30℃≥5万次的专项验证结果。

即：既不支持"已经达标"，也不支持"一定不达标"。

### 8. 下一轮优先验证

当前仍需要 -30℃ 专项耐折验证，才能对当前要求形成验证结论。

### 9. Sources

同 Q1（CASE-CA-2024-062 / REQ-AUTO-001 / LIT-LIT017 / STD-QBT2714）。

## 4. Q3｜下一步验证 Gold Answer

> 问题：面对当前-30℃≥5万次的新要求，下一轮研发最应该优先验证什么？为什么？

### 1. 当前需求

HD-S303 面层，汽车内饰革，耐折 -30℃≥5万次（REQ-AUTO-001）。

### 2. 风险预审结论

> 优先开展 HD-S303 针对当前应用条件的 **-30℃ 专项耐折验证**。

### 3. 历史相关 Evidence

CASE-CA-2024-062（E2）：同产品存在历史低温弯折风险（沙发革、-10℃）。

### 4. 标准 / 技术 Evidence

- STD-QBT2714（E3）：提供耐折测试标准依据；
- LIT-LIT017（E3）：提供 PTMEG/PPG 低温性能技术参考（-20℃）。

### 5. Evidence 等级

E2 + E3，无 E1 验证类证据（见第7段 Gap）。

### 6. 历史条件 vs 当前条件

历史温度（-10℃/-20℃）与应用（沙发革）不能直接覆盖当前条件（汽车内饰革、-30℃）。

### 7. Evidence Gap

> EG｜现有资料未发现/未明确说明 -30℃ 专项耐折验证结果——正是"优先验证什么"的直接依据。

### 8. 下一轮优先验证（理由）

优先开展 HD-S303 针对当前应用条件的 -30℃ 专项耐折验证，理由：

1. 当前客户明确要求 -30℃≥5万次；
2. 同产品存在历史低温风险（CA-2024-062）；
3. 标准（QB/T 2714-2018）提供耐折测试依据；
4. 技术资料（LIT-017）提供低温性能参考；
5. 历史温度/应用条件不能直接覆盖当前条件。

不得进一步自动给出最终配方。

### 9. Sources

REQ-AUTO-001 / CASE-CA-2024-062 / STD-QBT2714 / LIT-LIT017（同 Q1）。

## 5. 必须说 / 可以说 / 不能说

### 必须说

- 当前要求（HD-S303 面层，-30℃≥5万次）；
- 历史案例条件（沙发革、-10℃）；
- Evidence 等级（CA-2024-062 为 E2；标准/文献为 E3）；
- 条件差异（应用、温度）；
- Evidence Gap（-30℃ 专项验证结果未发现/未明确说明）；
- 下一步验证（-30℃ 专项耐折验证）。

### 可以说

- 历史案例提示低温风险；
- PTMEG/PPG 技术资料可以辅助理解机理；
- 历史项目可作为背景参考（PROJ-RD2024-002，Supporting）。

### 不能说

- HD-S303 已经满足 -30℃；
- HD-S303 一定不满足 -30℃；
- CA-2024-062 直接证明汽车革会失败；
- -20℃ 技术资料证明 -30℃ 结果；
- 推荐某最终配方已经可以解决问题；
- CASE-DETAIL-09 就是 CA-2024-062 详情。

## 6. Claim → Evidence 映射

| Claim | 必须支持的Evidence | Evidence等级 | 可否直接下结论 |
|---|---|---|---|
| 当前客户要求 -30℃≥5万次，HD-S303 为面层 | REQ-AUTO-001 | E1（锚点） | 可直接下结论（客户明确要求） |
| HD-S303 存在历史低温弯折案例 | CASE-CA-2024-062 | E2 | 可直接下结论（案例存在）；不可下"当前达标/不达标"结论 |
| 历史案例条件为沙发革、-10℃ | CASE-CA-2024-062 | E2 | 可直接下结论（案例记录条件） |
| PTMEG 低温性能优于 PPG（-20℃ 机理参考） | LIT-LIT017 | E3 | 仅作技术参考；不可直接下当前产品结论 |
| 耐折有测试方法标准（QB/T 2714-2018） | STD-QBT2714 | E3 | 可直接下结论（标准存在）；不可当作实测结果 |
| 当前 -30℃ 专项验证结果未发现/未明确说明（EG：基于当前已审阅资料范围，未发现 HD-S303 针对当前汽车内饰革客户"-30℃耐折≥5万次"的直接专项验证结果） | REQ-AUTO-001（证明存在明确的-30℃≥5万次要求）+ PROJ-RD2024-002（已审阅项目/阶段资料中未出现该专项验证）；EG来自"已审阅范围内未发现直接证据"，而非单条文档证明"企业没有做过"（支撑方式见表格下方说明） | EG | 可直接下"现有资料不足以判断"结论 |
| 优先开展 -30℃ 专项耐折验证 | REQ-AUTO-001 + CASE-CA-2024-062 + STD-QBT2714 + LIT-LIT017 | 综合（E1锚点+E2+E3） | 可作为建议结论；不得升级为配方结论 |

> **EG 支撑方式说明（-30℃专项验证 Gap）：**
> - REQ-AUTO-001：证明当前客户存在明确的 -30℃≥5万次 要求；
> - PROJ-RD2024-002：作为已审阅项目/阶段资料的一部分，其中未出现该专项验证；
> - EG 本身来自"当前已审阅资料范围内未发现直接证据"，而不是由某一条文档单独证明"企业没有做过"；
> - 统一表述保留："现有资料未发现/未明确说明"；不得写成"企业没有做过""项目没有做过""已经验证失败"。

## 7. Structured Output 草案（业务字段定义，不写代码）

| 字段 | 业务含义 |
|---|---|
| requirement | 当前客户需求文本与关键条件（产品 / 指标 / 应用） |
| risk_summary | 风险预审结论（先结论，后展开） |
| historical_evidence[] | 历史案例条目：evidence_id、来源、历史条件、Evidence等级 |
| technical_evidence[] | 标准 / 技术资料条目：evidence_id、来源、等级 |
| evidence_level | 各条 Evidence 的等级标注（E1/E2/E3/EG） |
| condition_gap | 历史条件 vs 当前条件的差异列表（应用 / 温度等） |
| evidence_gap | EG 结论（现有资料不足以判断之处） |
| recommended_validation[] | 下一轮优先验证项（按优先级排序） |
| sources[] | 每个关键判断的可追溯来源（文件 / 原始编号 / chunk） |

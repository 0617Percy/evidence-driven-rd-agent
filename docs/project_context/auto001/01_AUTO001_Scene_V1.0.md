## 4. 为什么值得做风险预审

基于资料事实与项目定位：

- 当前存在新的明确客户性能要求：-30℃耐折≥5万次；
- 当前资料尚不能直接证明该要求已经满足（未发现-30℃耐折验证结果）；
- 历史资料中存在HD-S303低温相关经验（CA-2024-062 低温弯折客诉，及同主题多条案例）；
- 因此值得在进一步投入研发/验证之前，调用历史Evidence做前置风险预审。

不引用夸大的商业价值数字。

## 8. Scene成功标准

本Scene成功不是"AI给出配方"，而是：

1. 找到相关历史Evidence；
2. 证据可追溯；
3. 区分直接证据与高相关参考；
4. 识别历史条件与当前条件差异；
5. 不做无证据外推；
6. 能形成明确Evidence Gap；
7. 能提出下一轮优先验证项。

## 9. 明确不做

本Scene不做：

- 其它5个汽车性能指标的完整开发；
- 自动配方；
- 性能预测ML；
- 质量归因；
- 多Agent；
- 全客户/全产品泛化；
- 全企业知识图谱。
